# 把原版参考图配准到模型画布，并量化"脸/头发/发饰大小位置与原版不符"

用户说"脸和头发的大小、位置和原版不一样"时，**先量后改**。本文件给出一套已验证可用的配准 + 量测流程（在 `work/pecorine-native/` 实测：全身像配准 IoU 0.773、瞳距/上睑两个独立指标给出同一差量 +12.7/+13px，与放大叠加图一致）。

## 0. 为什么不能直接目视调

画布、参考图、各层素材尺度互不相同，肉眼判断会把"素材尺度差"误读成"位置差"。配准给出一个可复述的变换 `canvas = k*ref + (ox,oy)`，之后所有差异都以**画布像素**报给用户，改与不改都能复核。

## 1. 选参考图（跳过这步会白干）

- 优先级：**最高分辨率的原版立绘 > 用户随手截的局部图**。截取过的图常被二次缩放或截边。
- 判据：把候选图各自配准一次，比较尺度是否成整齐比例。本仓库实例：全身像 768×1376 配准出 **k=0.6660**、偏移 (0,23)，而 768×2/3 = 512 = 画布宽 → **画布就是这张立绘按 2/3 缩放**；用户同期给的大头像 270×350 配准出 k=0.632（= 0.6660×0.948），且右边缘被截断。**结论：以全身像为基准**，大头像只能做参考，其"头发最宽处"等极值指标因截边而偏小（实测 145 vs 真值 155）。
- 截边自检：配准后看参考图占据的画布矩形是否顶到参考图自身的边界，且边界处有内容被切断。

## 2. 配准（轮廓 IoU 暴力搜索）

用 `scripts/register_art.py`（本技能自带，逻辑与实测一致）：

```bash
work/tools/python/Scripts/python.exe scripts/register_art.py \
  work/<char>-native/全身像参考图.png --lo 0.35 --hi 0.75 --step 0.01 --sub 4 --model-dir work/<char>-native --tag fullbody
```

- 目标掩膜 = 模型合成的 alpha（由 `source-manifest.json` 逐层 alpha_composite 得到）；源掩膜 = 参考图 alpha。
- 打分 `iou * (1 + 0.35*min(1, inter/area))`，粗搜 1/4 分辨率步长 2，再在胜出点 ±12px/±0.02 内全分辨率精修。
- 读数判据：**IoU ≥ 0.9 且 coverage ≥ 0.95** 才算同一张画（bust 实测 0.928/0.986）；0.75~0.85 属正常（模型是抠图重拼，缺件会拉低 IoU），但 coverage 仍应接近 1。
- 若最优解的偏移正好把参考图顶在画布边界上，那是结构关系（画布由该图缩放而来），不要当成偶然。
## 3. 量测（指标与做法）

模型侧**优先用 manifest 里的层 bounds 当"真值"**（眼层框、嘴层框、headwear 框都是精确已知的），不要从渲染图反推模型几何；渲染图只用来量"可见外观"。

| 指标 | 做法 | 已验证的判读价值 |
|---|---|---|
| 虹膜中心 / 瞳距 / 虹膜直径 | 青蓝掩膜 `(b>110)&(g>95)&(b-r>35)&(g-r>25)` + 闭运算，取面积≥40 的块，限制在脸框 x 范围内（否则发饰宝石、蓝灰衣饰会被当成眼睛） | 眼位差、瞳距差；两图**同一掩膜**测出的直径比才是有效尺度比 |
| 上睑最高暗像素 | 眼中心 ±20px 窗口内 `dark=(r<140)&(g<130)&(b<150)` 的最小 y | 与虹膜质心互相独立的第二证据，二者一致才下结论 |
| 可见脸轮廓（宽/下沿） | 肤色连通域中**包含脸颊探针点**（双眼中点下移 14px）的那一个，取 bbox | 排除发丝高光被误判成皮肤；下巴实际会被颈部皮肤连成一体，别拿它的 bottom 当下巴 |
| 发际线 / 刘海下沿 | 逐画布列扫：该列脸部连通域肤色最高行 = 发际线；该列头发最高行（限眼线以上）= 刘海下沿 | 量出"额头露多少"，比量某一个点更稳 |
| 头顶弧顶 | 头发掩膜行宽 > 0.4×最大行宽的最小 y（排除细呆毛） | 头发整体高低 |
| 发饰 | 红掩膜限制在头部 y 范围内取最大块 | 只能给大致位置：头发暗红阴影同样满足 `r-g>50`，会撑大 bbox |

量发际线/刘海高低先跑统一探针 `scripts/hairline_probe.py`（皮肤锚定发际线 + 前发 alpha 发梢，模型合成可 `--drop` 剥离干扰层、`--fronthair-bounds` 重建 before 对照，直接出逐列差量与中位数）；`face_metrics.py`/`hairline.py` 等旧脚本的口径坑见 §5。

参考图侧所有坐标经 `canvas = k*ref + (ox,oy)` 换算后再与模型侧同单位对比，输出"模型 − 参考"的差量表（`face_metrics.py` 的 `=== delta ===` 段即此格式）。

## 4. 目视复核（必做）

生成三格图 `参考 | 模型 | 50% 叠加`，**叠一张每 10px 一条、每 50px 带坐标标签的画布网格**，放大 3~5 倍，再按部位切：头顶/眼/嘴下巴。数值与目视一致才向用户汇报。

```bash
work/tools/python/Scripts/python.exe zoom_cmp.py --align debug_analysis/align_fullbody.json --image 全身像参考图.png --tag full
```

叠加图里成对出现的"重影"就是差量：重影间距 ÷ 放大倍数 = 画布像素差。

争议部件与相邻层轮廓混淆时（前发叠在后发上最常见），模型侧要出**剥离干扰层的中性合成**：按争议对象丢掉干扰层（前发争议丢 `backhair`），并顺手丢掉 `facedetail_*` 与 `mouth_open` 这类会叠出重复五官的开关层（保留 `mouth_close`）；参考侧保留完整原画，图注写明剥离了什么。改前/改后/参考三格必须同一合成口径，否则前后发轮廓混在一起，读数与目视都无法归因。

## 5. 常见坑

- **掩膜误判三连**：发丝高光 → 皮肤；蓝灰衣饰 → 虹膜青；头发暗红阴影 → 丝带红。每个掩膜都要先用"画在图上"的方式确认命中的是自己要的东西。金色头发掩膜还会命中**皮肤与阴影皮肤**（`r−b>50` 与肤色区间重叠），`loose & ~skin` 仍会漏到下巴——"发色最低行"会落在颈颌处而不是发梢；发际线一律用皮肤锚定口径（脸连通域逐列最高行），发梢用前发图层 alpha。
- **限制窗口**：所有特征检测都要加画布范围的 y 上限（如 head_limit_y）与 x 窗口，否则胸口/肩带会进榜，眼位会被量到 y=280 的泳衣上。
- **别用单一指标**：虹膜色块只命中虹膜亮部（暗环与瞳孔不命中），绝对直径会偏小——只把它当**相对尺度**用（两图同掩膜比），绝对值取规范里的数。
- **脸/颈/胸的皮肤是连通的**，"下巴"不能用连通域 bottom 表示；只对比两图同法测出的量，避免把"连通域差异"当成脸形差异。
- **测量脚本的打印**：特征字典里混装 2/3/4 元组与标量时，先按 `len(value)` 分派再 `:.0f` 格式化，否则 `float is not subscriptable` / `tuple index out of range` 会连续打断多次运行（本会话踩了 3 次）。
- **模型合成图 vs 渲染图**：合成图（按 manifest 贴层）能看清每层位置，但它把所有表情层都叠上（嘴会同时出现张口与闭口）；渲染图才是实际观感。量几何用前者，判观感用后者。
- **带眼线上限的口径量不了"刘海压眼"类缺陷**：`rows < eye_y + 4` 这类行过滤会把缺陷本身（垂到眼开口的发梢）裁掉，测出的"刘海下沿"是钳在眼线上的假值。量发梢用前发 alpha 的逐列最低行（只开 y<230 窗口），与皮肤锚定发际线一起报。
- **"首个连续段"不能当发梢定义**：发丝间 2–5px 间隙会把段打断，返回呆毛/颅顶段而不是刘海尖；用限窗逐列极值。
- **重跑旧测量脚本前先查它的模型侧输入**：render 路径、rect、eye_y 常量都是按当时那版构建烘焙的，直接跑会量到**上一轮的旧构建**且不报任何错。核对输入文件 mtime，显式传 `--render-path/--render-rect` 指到本轮 1:1 渲染再读数。
- **青色块数 ≠ 2 的运行直接作废**：`found[0] / found[-1]` 配对会把发饰、衣服青块当第二只眼，eye_y 一带偏，所有带裁剪的下游指标全部污染（合成图叠满表情层时必现）。
- **before 对照图别从"只存受影响文件"的备份目录逐层合成**：缺失层被静默跳过，before 退化成近乎空图（皮肤像素 605 vs 69464 都不报错）。before 合成 = 当前共享素材 + 旧 bounds/旧素材覆盖（`hairline_probe.py --fronthair-bounds` 即此）；出图后先做像素量级自检。
- **小尺寸参考图的检测窗口别卡太紧**：参考图很小时（如 270×350），"虹膜块限制在图高 55% 以上"会 0 命中（眼睛实际在 58% 高度）；放宽到 75% 并靠 x 窗口（脸框）排除发饰宝石、泳衣等假阳性。
- **浅黄/金色掩膜（发饰玫瑰）不可比质心**：参考图里玫瑰与下方宝石、暗部连成一块，模型侧是干净的一朵，两者 bbox/质心都不可比；只能比左上边缘或直接用放大叠图目视。
- **嘴部红掩膜在本项目两图都命中脸颊阴影** → 该像素指标作废；模型侧直接读 `mouth_*` 层 bounds，参考侧靠放大图目视。

## 6. 量完之后

不要把"统一上移 N px / 拉伸 X%"直接落盘。把差量、两三种修法（移动 vs 缩放 vs 重贴素材）及各自副作用（如整体上移会让额头比原版多露、垂直拉伸会把侧发末端也拉下去 30px 压到肩）列成选项交用户裁决——艺术效果归用户。用户选定后再按第 7 节落地。

## 7. 落地与复测（配方已在 pecorine-native 实测：眼位残差 ≤1px、发际线 ≤1.5px、弧顶 ≤1px）

写一个独立步骤脚本（`work/<char>-native/adjust_*.py`），带 `--dry-run` 先打印所有将要改的 bounds 与重映射参数，确认后再落盘；先把受影响图层 + manifest + PSD 备份进新 `_backup_pre_<step>/`。

### 7.1 首选：整组刚性平移

按组改 manifest 的 bounds（`top/bottom ±N`，不动美术）：

| 组 | 图层 |
| --- | --- |
| 脸组 | `face`、`eyewhite-*`、`irides-*`、`eyelash-*`、`eyebrow-*`、`mouth_open/close`、`facedetail_*` |
| 头发组 | `fronthair`、`backhair`、`headwear` |

眼/眉/嘴是**独立图层**，跟着脸组一起平移就能精确落到原版眼位——不要试图只挪 `face`。改层坐标会改变 PSD2Live 重新生成的变形器位置（自动重算），但动手前先确认该角色的 `export_*.py` 里**没有硬编码的层坐标**（本项目靠 mesh positions 计算，安全）。

### 7.2 需要改"发量长度"时：区间纵向重映射，不要整体拉伸

只在弧顶已在正确位置、而发际线仍需下压时用：

- 画布锚点：`crown`（弧顶，钉住）、`hairline`（当前刘海下沿）、`target`（原版刘海下沿）。
- 拉伸系数 `s = (target - crown_new) / (hairline - crown_new)`，其中 `crown_new = new_top + crown_local`。
- 逐行映射：`r ≤ crown_local → r`；`crown_local < r ≤ hairline_local → crown_local + (r-crown_local)*s`；`r > hairline_local → 刚性平移`（最后一段必须刚性，否则同层的侧发被一起拉长）。
- **锚点换算必须用旧 top**：`crown_local = CROWN_CANVAS - old_top`、`hairline_local = HAIRLINE_CANVAS - old_top`——此刻美术还没移动；用新 top 会让 s 与锚点不自洽（本会话先踩过这个坑）。
- **不要在层内用"alpha 行宽 > 0.4×max"自动找弧顶**：它可能落在可见弧顶之上（被遮住或掩膜不认的部分），得用**合成图上量到的弧顶画布值减旧 top**。
- 重采样用反向映射 + 双线性插值，并**先乘 alpha 再插值（预乘）**，否则透明区的无色像素会把边缘插出黑边。
- 副作用一并汇报：区间以下刚性平移会把侧发末端整体下移（本项目 14px）。

### 7.3 复测（同一套指标，逐项跑完再汇报）

1. `face_metrics.py --render --render-path <新渲染图>` 出与改前同一格式的 delta 表，逐项看是否进到个位数像素。
2. 九姿态拼图（±30° 转头、俯仰、倾斜、bodyX、闭眼+开口、hair 参数、表情各一格）逐格目视：破面、接缝、头发随头形变。
3. 重映射区域单独出**头部特写**：查条纹、模糊、发丝断裂、渗色。
4. `npm test`；export/public/dist 三处 moc3 md5 一致。
5. 追加编号小节到 `docs/HANDOFF.md`，保留 `_backup_pre_<step>/`；可复用的量测/渲染脚本一并写进交接，便于下轮复现。

### 7.4 汇报口径

对齐后仍会剩下**美术层面**的差异，必须主动写清、不要藏：同掩膜下的虹膜直径比、可见脸宽差（侧发遮挡不同）、发丝间隙疏密（原版刘海更密、模型更透）。这些不是几何问题，继续挪坐标只会引入新错。
