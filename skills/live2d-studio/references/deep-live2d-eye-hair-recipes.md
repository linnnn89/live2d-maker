# 眼睛与头发的重切做法（按 PSD_LAYER_SPEC）

先读 `work/tools/psd2live/docs/zh/spec/PSD_LAYER_SPEC.md` 的那一节，下面只是可执行化的配方。核心前提：**若原始美术素材（如 `source/eye-l.png`）与画布上的图层框是同一比例**（例如素材 315×229 对应画布框 33×24，比例一致），就可以直接从原画重切，比修合成图更忠于美术。

## 眼三层重切（先用 numpy/PIL 量，再切）

1. **量**：把原画素材和它在画布上的框对上，确认缩放系数（两边长宽比一致即可直接 resize）。眼球框坐标从 `source-manifest.json` 或 PSD 层 bbox 取。
2. **眼白 `eyewhite`**：取最大不透明连通域，`scipy.ndimage.binary_fill_holes` 成实心眼眶 → 只保留眼内轮廓内的部分，用**逐行从原画采样**得到的眼白渐进去填（不要用纯白）。
3. **虹膜 `irides`**：从原画抠出"虹膜+上缘深色"，`fill_holes` 成完整圆；圆心取前景质心、半径取前景到质心距离的 99 分位，按此画**完整圆**（规范要求圆，由眼白作裁剪蒙版）。
4. **补虹膜上被睫毛盖住的像素**：用 `scipy.ndimage.distance_transform_edt(~valid, return_indices=True)` 做最近有效邻居内插，避免虹膜出现缺口。
5. **睫毛 `eyelash`**：只取原画的深色**上睑/睫毛带**。色相过滤很关键：深色且 `(blue - red) < 15`，用来排除虹膜自身的蓝青色，否则睫毛会连成一片把眼球吞掉。**严禁**包进下眼线/下眼眶线。
6. **缩放回画布框**：必须先**预乘 alpha** → LANCZOS resize → 反预乘，否则半透明边缘在缩放后出现深色描边。
7. 备份旧层到 `_backup_pre_eye_rebuild/` 再覆盖；改完渲染睁眼/闭眼/视线极限三组确认眼白不再溢出、闭眼无残留虹膜。

## 前后发切分

- 判定标准是**下巴线**（脸/头层的下边界，可从 `face.png` 的 bbox 推）而不是"看起来像长发的地方"：下巴线以上、位于脸前的 = 前发（刘海）；下巴线以下垂到身体两侧的 = 后发。
- 切的时候让两段**重叠约 10px**。物理摆动时后发离开原位，零重叠会在接缝处露出空白。
- 切完先算一下"把下半部分从当前层移除、改由后发承载"会**损失多少可见像素**：落在身体剪影内的后发像素本来就被身体挡住（不可见），只要可见损失接近 0 就说明切分位置正确；损失明显就别切。
- 后发必须是 PSD 最底层（manifest 第 0 项），`body/face/eyes` 全部排它上面，前发排最上。改完用 `deep-live2d-psd2live-semantics.md` 的探针确认 `ParamHairBack` 真能带动它。

## 表情层（如腮红）去留

- `facedetail_*` 是 FACE_DETAIL 开关层（由参数切换显示）。"去掉"= 从 manifest 与 PSD 移除，**PNG 保留**以便恢复，并在工作记录里写明。
- 移除后若颜色仍在，先确认它来自 `face.png` 本身画上去的妆（不是被移除的那层），再向用户说明，不要静默继续擦美术。定位方法：把要查的层的脸颊区域换算成层内坐标裁出来，按粉色特征 `(r>200)&((r-g)>40)&((b-g)>10)&(g<215)` 数像素并 dump 出现频次最高的几个色值；粉色只落在 `face.png` 本体就说明妆是烤进图里的——只能对两颊做去色/补绘（用周围肤色内插），删层或改 manifest 都无效。

## 把新画的素材（刘海/后发/眼睛）换进画布

用户拿新画的素材（AI 出图或重画）要"换进去试试"时的配方。核心：**先量素材自身的内部结构，再定缩放与落位**；不要拿整行宽度当"头宽"。

1. **选锚点**：用素材内部可辨、又不受附带装饰影响的纵向跨度——首选「头顶 → 发际线（刘海下沿跨过脸中线处）」。行宽不能用：发饰、垂发、辫子会把整行宽度撑大，量出的"头宽"毫无意义。
2. **量头顶**：取上半部分第一个行宽 ≥ 0.5 × 该区域最大行宽的行，这样会跳过呆毛/细发丝，落在真正的头顶上。
3. **量发际线**：人脸中线 ±20px 的窗口里被头发**整窗连续覆盖**的最后一行。只看单列会被发丝之间的细缝切断（实测同一张素材单列给出 60 行、整窗给出 263 行的两倍多跨度）；窗口宽度取 ~40px，并要求 `window.all()`。
4. **定缩放与落位**：`k = (参考图的头顶→发际线 画布像素) / (素材的该跨度像素)`；横向把素材质心对到脸中线。落位后**必须回报三个数**：发际线落在画布 y 几（与参考的 y 比）、头部发量宽变成多少画布像素（与参考比）、自带发饰的中心落在哪（与参考的发饰位置比）。三者都接近才能进 PSD 重建。
5. **先出图层合成三联预览再重建**：旧素材 / 新素材 / 原版参考，裁到头部并排一张图。合成预览能一次暴露落位错误，比跑完整 PSD+导出+渲染链路快得多；确认后再 `--apply` 写层 + 改 manifest。
6. **新素材常自带原属其它层的部件**（发饰、垂链）：若新图自带发饰，就把老 `headwear.png` 改名移开（如 `source/_trial_headwear_off.png`），让重建脚本给它生成同尺寸透明占位——层仍在 manifest 里、绑定与参数不丢、不会出现双发饰，也随时可复原（比删层安全）。
7. 合成预览会把所有 `facedetail_*` 同时叠上，脸颊的粉/红是**预览假象**，不要当成"腮红没去干净"上报；这类判断只看真渲染。
8. **仿射变换（平移+旋转）注意 PIL 方向**：`Image.transform(AFFINE)` 是逆映射（输出→输入），旋转角取反（`θ_pil = -θ`）。旋转后必验证：取素材最左/最右列 alpha 像素 y 均值差，符号应与预期倾斜方向一致。
