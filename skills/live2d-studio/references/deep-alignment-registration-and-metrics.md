# 特征地标配准与指标选取

## 1. 为什么不能只用轮廓 IoU

轮廓 IoU 的用途只有两个：定尺度，以及判断「这两个图形是不是同一张画」。它的偏移量在下列输入下**信息量不足**：

- 画布是参考图的局部（例如只画到大腿），差异集中在画布之外；
- 参考图经过裁切／二次缩放。

量化感受（同一份数据的实测）：正确偏移 IoU 0.747 / coverage 0.971，75px 外的错误偏移 IoU 0.754 —— 差 0.7%，排序反转。这类「平坦最优」无法通过调阈值解决，只能换锚点。

**可行做法**：用配准先定尺度（尺度的 IoU 峰是尖锐的，偏移的峰不是），偏移改用地标反解。

## 2. 地标配准代码骨架

```python
# 1. 在两图里检出同一特征（例：虹膜青蓝掩膜，闭运算后取连通域）
#    m = vis & (b>110) & (g>95) & ((b-r)>35) & ((g-r)>25)
# 2. 按面积配对：取面积最大的两块，左右排序后一一对应
#    （面积是最稳的配对钥匙：同一张画里同一特征面积相等或按缩放比平方变化）
# 3. 解变换：
#    k  = (target_x[1]-target_x[0]) / (ref_x[1]-ref_x[0])        # 也可用 y 或两者平均
#    ox = target_x[i] - ref_x[i]*k   （i=0,1 各解一次，必须吻合）
# 4. 校验（两个都要看）：
#    - 两个地标解出的 (ox,oy) 差异 < 1px
#    - 面积比 ≈ k^2（证明是同一张画且没有非线性处理）
```

陷阱与处置：

- **假阳性块**：整幅图里同色系的东西（宝石、蓝灰衣饰、暗部反光）都会命中掩膜。**限制在头部带内（例如上 40%）并设最小面积**（≥150px），再取最大的两块，比全局取首次命中稳得多。
- **掩膜不变量要同源**：量「开口/眼白」这类形状时，参考侧与模型侧要用**同一套阈值**，否则得到的是阈值差不是几何差。
- **眼位这类小目标的掩膜会互相污染**：搜索框要收紧到单只眼睛，否则相邻的发饰宝石会把质心拉偏（实测左眼质心被拉到 289.5 而真值 280.5）。

## 3. 指标选取表

| 指标 | 是否抗头发污染 | 用法 |
|---|---|---|
| 图层 bounds / manifest 几何 | 是（精确已知） | 模型侧几何的「真值」，优先用 |
| 瞳孔中心、虹膜直径 | 是 | 跨版本比较、配准校验 |
| 配色掩膜测得的「可见眼开口」 | 部分（受睫毛/发丝影响小） | 定素材尺寸，需两侧同阈值 |
| 可见脸连通域（脸宽/下巴/眼到下巴） | **否** | 只在头发配置完全相同的两次测量间可比；跨头发改动禁用 |
| 发际线／刘海下沿 | 是（用「脸中心被头发覆盖」定义） | 换刘海素材时的主锚点 |
| 不变量归一化的比例（头宽/眼距、虹膜/眼开口） | 是 | 判「眼睛显小」「脸偏大」这类比例问题；只看绝对尺寸会得出相反结论 |
| 渲染图不透明像素 bbox 的上沿/外沿 | 是（前提：该渲染已验证 1:1） | 量外凸部件（呆毛、发梢、发饰）的长度 |

## 4. 目视复核套路

1. 生成 3 联图：参考图（已配准到画布）| 改前 | 改后，裁到同一区域，同一缩放倍率。
2. 关键区域再加 6–10 倍放大 + 网格坐标标注，逐项点名检查（露空、断层、补丁边、色块、硬边、锯齿、半透明残影）。
3. 叠图查看时用「半透明叠加 + 描出参考特征框」，比并排更容易看出系统性偏移。
4. 目检结论与数值结论必须一致；不一致时先怀疑指标（尤其脸连通域类），不要先怀疑美术。

## 5. 渲染图的可信度：先标定变换，再量像素

**带适配（fit）的 viewer 里 zoom 1 不是 1:1。** 典型实现 `fit = min(1.86/canvasH, 1.86*aspect/canvasW)`，zoom=1 时 1 画布像素 ≈ 0.93 渲染像素。把这种 PNG 当画布直接量，会把所有尺寸按同一常数缩小，并**伪造出「整体位移」的假象**（实测：图层真值眉 y138–142、睫毛 y148–162，渲染图量到 y165–167、y174–186）。

**一眼分辨是缩放还是位移**：两侧内容 bbox 的**中心相同、尺寸差常数比例**（本例中心同为 (256,514)、比例 0.93）→ 纯缩放误差，模型没有动；中心也不同才是位移。

**定标循环（不依赖任何公式，收敛快）**：

1. 取模型自身 drawable 边界并集（画布坐标，只算 opacity>0 的 drawable）作为 `want`；
2. 渲染一次，取 PNG 不透明像素 bbox 作为 `got`；
3. `zoom *= ((want_w/got_w) + (want_h/got_h))/2`，`cx,cy = 画布中心`，重复到 `|k−1| ≤ 0.002`（本例 1–2 次收敛）；
4. 渲染完成后**再断言一次** `max|got−want| ≤ 2px` 并把数值打印出来。

把它做成渲染脚本的 `exact` 开关（画布尺寸必须与模型画布一致），并让**所有**截图都打印真实 px/画布比例；非 exact 的图不得用于量尺寸。校验用 `max|got-want|` 这类自洽断言 —— 用输出自己的公式去校验自己（如 `ppc = fit*zoom*cv.height/2` 而 zoom 由同一函数反解）是同义反复，测不出错。

**同口径比较时的掩膜注意**：

- 参考图背景是白底时，近白像素会通过肤色类阈值（`r>232`、`b>150`、`r−b<75` 逐条都成立）→ 必须显式排除近白，否则「头宽」会量出整幅图宽（实测每行都得到恒定 280px 的假值）。
- 美术被缩小后细线（睫毛、眼线）变淡，深色掩膜会**少计**：同一特征模型侧比参考侧窄 15–30% 可能全是掩膜效应。用小量差异下结论前，必须用放大并排目视复核一次。

**把参考图放进画布帧的方向**：`canvas = k·ref_px + (ox,oy)` 意味着**乘 k（缩小）后平移**。写成 `1/k` 放大出来的参考帧不会报错、能叠加能度量，但所有逐行比较都在错的尺度上跑（实测把 270×350 的头像放大成 769×1538 后，「头宽」量到整幅图宽、虹膜掩膜一个都找不到）。落地后先自检一次：参考帧里已知地标（瞳孔中心）应落在解出的画布坐标上。

**轮廓极值要用同类掩膜**：模型侧的图层 alpha 与参考侧的非白描边不是同一类掩膜；参考图细淡的外描边会把它自己的轮廓读高／读大，从而诱使你去修正一个本来正确的长度（头顶、呆毛尖、外沿都适用）。比极值时两侧统一用「实心主体」掩膜，或统一用 alpha／非背景。
